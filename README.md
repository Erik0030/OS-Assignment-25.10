## Features
- Calculates Turnaround Time, Waiting Time, and Response Time.
- Computes averages for each metric.
- Generates a visual Gantt Chart representation of execution order.
- Dynamically handles any number of processes with differing arrival and burst times.

## How to Compile and Run

Open your terminal in Linux.
Compile the program using gcc:
   ```bash
   gcc schedule.c -o schedule
Run via ./schedule
